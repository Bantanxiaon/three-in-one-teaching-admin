# 系统运行方式

1. Next.js 提供多语言登录和工作台，登录调用 Auth.js Credentials。
2. credential-auth 验证格式、失败计数、用户启用状态与 bcrypt 密码，失败统一返回空值。
3. JWT 保存角色与首次改密标记；session 暴露用户 ID/角色，不返回密码哈希。
4. 页面 guards 验角色/首次改密，API 再校验权限及资源归属。
5. Prisma/PostgreSQL 管理申请、用户、教学档案、课次、课时包/流水，关键变更使用事务和审计。
6. 邮件模板渲染后使用自己的 Resend，保存发送接受记录，由签名 Webhook 更新投递状态。通知失败不等于业务保存失败。
7. 小程序微信身份与自己的服务会话，和网页 Auth.js Cookie 是不同认证路径。
8. S3/R2 预签名上传仍需配置自己的桶权限与私有媒体访问策略。

优势：服务端权限检查；教学流程和课时流水整合；有审计/投递追踪；管理栏目按需加载并保留面板。

成本：模块依赖多，不是独立认证 npm 包；需数据库和服务运维。会话撤销、密码策略、临时密码设计、安全备份仍需完善，详见 SECURITY.md。数据字段不代表完整支付/日历同步。

使用普通登录页和后台必要样式，不包含原官网动画、液态玻璃、真实照片和宣传内容。
