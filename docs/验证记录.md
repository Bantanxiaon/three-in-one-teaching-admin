# 验证记录

开源提取日期：2026-10-15。

本地没有连接原网站数据库。原网站此前的 619 项测试不等于本仓库验证结果。本仓库的安装、类型、lint、测试、构建与渲染结果将在检查完成后更新。

GitHub Actions 使用独立 PostgreSQL 16 服务和每次生成的随机测试密钥/密码，依次执行空库迁移、seed、类型、lint、测试、构建，以及未登录拒绝 -> CSRF -> 密码登录 -> 会话 -> 管理 API/页面 -> 退出 -> 拒绝的完整流程。不使用原网站凭据。

CI 是否通过应以仓库实际 workflow run 状态为准，提供 workflow 文件不代表它已经运行成功。
