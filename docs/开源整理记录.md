# 项目说明

登录三端合一教学后台管理系统，覆盖管理员、教师、学员三端统一认证与教学业务。

- 统一登录、角色权限、首次改密与账号管理。
- 申请审核、学员档案、教师分配、排课、出勤核销、课时流水与教学反馈。
- 邮件模板、投递状态、审计日志、可选微信与对象存储集成。
- 中英日路由、PostgreSQL/Prisma 模型和迁移、自动化验证。
- 提供空库初始化和虚构演示档案，没有默认管理员密码。
- 图片预览来自应用实际运行，使用隔离测试数据库中的演示数据。
- 官网宣传资源、真实个人资料、私有部署配置和凭据不公开。

安全边界和现有设计限制见 SECURITY.md。数据库初始化仅用于自己明确确认的空数据库。
