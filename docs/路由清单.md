# 路由清单

[locale] 为 zh/en/ja。路由公开不等于允许匿名访问，权限以代码 handler/guards 为准。

## 网页

| 路径 | 用途 |
| --- | --- |
| /[locale]/login | 邮箱密码登录 |
| /[locale]/change-password | 已登录改密 |
| /[locale]/admin | MANAGER/ADMIN/SUPER_ADMIN |
| /[locale]/portal | 按角色跳转 |
| /[locale]/portal/student | 学员工作台 |
| /[locale]/portal/teacher | 教师工作台 |

## Auth.js 子路径

catch-all 处理 session、providers、csrf、signin、signout、callback/credentials 等。请用 next-auth/react 的 signIn/signOut/getSession，不绕过 CSRF 流程手拼认证请求。

业务 API 可能要求网页会话、角色、归属、改密状态、小程序认证或 Webhook 签名，不是匿名接口清单。
